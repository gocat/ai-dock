# Resources and third-party review

This build bundles AI Dock source, its locally drawn application icon, and the separately licensed launcher SVG assets listed below. It uses AppKit and system-provided SF Symbols at runtime; it does not redistribute the SF Symbols application or extracted symbol files.

The following development assets are excluded from Git, the default build, and the review source package:

| Asset | Origin | Reason for exclusion |
| --- | --- | --- |
| `Codex.png` | Installed OpenAI desktop application | No public redistribution permission established |
| `CodexMono.svg` | Local cloud-terminal adaptation | Not an approved official monochrome asset |
| `ClashMono.svg` | Clash Verge Rev upstream `src/assets/image/icon_light.svg` | Upstream repository has GPL-3.0 license; asset-specific redistribution/trademark basis has not been separately established |
| `Protocol/` | Generated by the installed Codex CLI | Reference only; not needed to build or execute this app |

Default buttons use monochrome Codex and Clash identifiers; other proxy applications use a neutral shield. No affiliation or endorsement is claimed. Local development can explicitly opt into `bash build.sh local-icons`; that output is not the proposed public package.
